Stop future raw prompt writes in Python pipeline audit rows while preserving useful redacted debugging metadata.

</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Prompt construction to LLM provider | Prompts contain resume/JD/private content before leaving the process. |
| Agent process to PostgreSQL audit rows | Agent code writes prompt trace metadata to persistent storage. |
| Pipeline audit rows to API/SSE/debug clients | Persisted audit data may be queried or exposed later. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-08A | Denial of Service | `agents/resume_tailor.py` no-Vault path | mitigate | Add a pipeline-agent test proving empty future approved evidence does not abort existing base resume/profile tailoring per D-01. |
| T-11-09 | Information Disclosure | `agents/resume_tailor.py` prompt trace | mitigate | Replace raw prompt payload with hash/length/redaction metadata per D-08 and D-09. |
| T-11-10 | Information Disclosure | `agents/quality_analyst.py` prompt trace | mitigate | Replace raw prompt payload with hash/length/redaction metadata per D-08 and D-09. |
| T-11-11 | Repudiation | `llm_prompt_trace` events | mitigate | Preserve event type and identifiers while removing raw private content so debugging still has a durable trace. |
| T-11-12 | Tampering | Redaction helper misuse | mitigate | Tests assert forbidden keys and raw values are absent from serialized payloads. |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No package installs are planned; `hashlib` and `json` are Python stdlib. |
</threat_model>
