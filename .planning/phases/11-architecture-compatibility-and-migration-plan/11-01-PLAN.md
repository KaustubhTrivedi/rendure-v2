<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client to Hono jobs API | Untrusted job IDs, URLs, and route requests cross into API handlers. |
| PostgreSQL pipeline_events to SSE clients | Stored audit rows are serialized to user-visible event streams. |
| Downstream v4.1 domains to existing job clients | New Vault/application fields could accidentally alter existing clients. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | `api/src/job-submission.ts` | mitigate | Tests assert URL submission remains pipeline-only and does not require Vault/evidence/application tables per D-01. |
| T-11-02 | Information Disclosure | `api/src/sse.ts` | mitigate | Serializer tests assert DB-only `payload` is not emitted to SSE clients per D-08 and D-09. |
| T-11-03 | Denial of Service | `GET /jobs/:id/events` | mitigate | Existing listener tests and added terminal-status assertions preserve stream close behavior for terminal pipeline statuses. |
| T-11-04 | Repudiation | Job API route contracts | mitigate | Route contract tests preserve job detail/status/QA fields needed to explain pipeline outcomes. |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No package installs are planned; existing lockfiles remain unchanged. |
</threat_model>
