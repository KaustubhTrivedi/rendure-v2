<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AI extraction to trusted Career Vault evidence | AI-created candidates must not become trusted records without explicit user approval. |
| Missing evidence suggestion to user-visible claim | Suggested evidence must be backed by source attribution. |
| Draft/action generation to external side effects | The product may draft/copy/render but must not submit applications or send email automatically. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-13 | Tampering | `assertTrustedEvidenceWriteAllowed` | mitigate | Reject AI-initiated or unsourced trusted evidence writes. |
| T-11-14 | Spoofing | `assertMissingEvidenceHasSource` | mitigate | Reject missing-evidence candidates with no source artifact/reference/excerpt. |
| T-11-15 | Elevation of Privilege | `assertManualOnlyAction` | mitigate | Reject submit/apply/send action types while allowing copy-only/PDF actions. |
| T-11-16 | Information Disclosure | No-send boundaries | mitigate | Static tripwires reject automatic email-sending integrations that could leak recruiter/private data. |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No package installs are planned; tests use existing Vitest and Node stdlib. |
</threat_model>
