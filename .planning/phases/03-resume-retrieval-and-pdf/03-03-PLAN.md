<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→PDF route | Untrusted `:id` and `:version_id` select DB source and trigger subprocess rendering. |
| PDF route→render helper | Stored resume source and DB-confirmed version ID cross into filesystem/subprocess code. |
| API startup→host environment | API probes host `rendercv` binary and logs availability. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | PDF route SQL | mitigate | Use `pool.query('SELECT latex_source FROM resume_versions WHERE job_id = $1 AND version_id = $2', [id, versionId])` only. |
| T-03-02 | Information Disclosure | PDF route version ownership | mitigate | Same `WHERE job_id = $1 AND version_id = $2` predicate and uniform 404 for unknown/cross-job IDs. |
| T-03-03 | Tampering | PDF cache path | mitigate | Route never accepts paths; render helper derives `<version_id>.pdf` from DB-confirmed UUID and fixed cache dir. |
| T-03-04 | Information Disclosure | PDF error responses | mitigate | Map RenderCV errors to sanitized RFC7807 hybrid bodies with `rendercv_unavailable`, `render_timeout`, or `render_failed`; no raw stderr in body. |
| T-03-05 | Denial of Service | PDF render endpoint | mitigate | Route delegates to render helper that enforces timeout, process-wide concurrency cap, and in-flight dedupe. |
</threat_model>
