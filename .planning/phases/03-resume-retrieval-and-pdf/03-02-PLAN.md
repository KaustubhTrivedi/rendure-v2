## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route→render helper | DB-confirmed `version_id` and stored source enter filesystem/subprocess code. |
| render helper→filesystem | Helper writes temp files and immutable PDF cache files. |
| render helper→RenderCV subprocess | Stored resume source is rendered by external host CLI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-01 | Tampering | SQL injection | accept | No SQL in this plan; route SQL is covered in Plan 01/03. |
| T-03-02 | Information Disclosure | Cross-job lookup | accept | No DB lookup in this plan; route ownership query is covered in Plan 01/03. |
| T-03-03 | Tampering | `api/src/resume-render.ts` cache path | mitigate | Validate UUID `versionId`, derive filename only as `<version_id>.pdf`, use fixed cache dir from env/default, reject path separators. |

| T-03-05 | Denial of Service | RenderCV subprocess | mitigate | Enforce `RESUME_PDF_RENDER_TIMEOUT_MS`, process-wide `RESUME_PDF_RENDER_CONCURRENCY`, and in-flight dedupe map. |
